
This repository contains the data extracted for the systematic literature review:

**A Systematic Literature Review of Lightweight Machine Learning for Breast Cancer Detection**

## Description

The dataset contains information extracted from the studies included in the systematic literature review of lightweight machine learning techniques for breast cancer detection.

The extracted information includes, where available:

- Publication information
- Datasets and data modalities
- Lightweight machine learning techniques
- Taxonomy classifications
- Predictive performance metrics
- Parameter counts
- GFLOPs
- Model size and memory information
- Inference time and latency
- Deployment information

The extracted data were used to support the taxonomy, comparative analyses, and visualizations presented in the manuscript.
